# Backups y recuperación

No se pudo demostrar backup ni restauración en esta auditoría read-only.

Pendiente documentar proveedor, frecuencia, retención, cifrado, RPO/RTO y dueño.
Ejecutar restore en proyecto aislado con checksum y prueba de lectura de productos,
leads, cotizaciones y logs. Recomendación inicial: RPO ≤24 h y RTO ≤4 h para datos
comerciales, sujeto a validación del negocio.
