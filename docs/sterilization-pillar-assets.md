## Fuentes normativas enlazadas

- Ministerio de Salud, [Resolución 914 de 2025](https://www.minsalud.gov.co/Normatividad_Nuevo/Resoluci%C3%B3n%20No%20914%20de%202025.pdf), manual de buenas prácticas para reprocesamiento de dispositivos médicos.
- SUIN-Juriscol, [Resolución 3100 de 2019](https://www.suin-juriscol.gov.co/viewDocument.asp?id=30039964), fuente histórica de habilitación.

La normativa de habilitación tuvo modificaciones durante 2026. La página no afirma vigencia, transición ni cumplimiento de una resolución concreta; exige validación jurídica y ante autoridad competente para proyecto real.
